# Contributing to Social Application

Thank you for your interest in improving this project. Contributions are welcome and appreciated.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Make your changes with clear and focused commits.
4. Test your changes locally.
5. Open a pull request with a clear description.

## Contribution Guidelines

- Keep code clean and readable.
- Follow the existing project structure and naming patterns.
- Use meaningful commit messages.
- Avoid unrelated changes in the same pull request.
- Document new features or major updates.

## Local Setup

```bash
git clone <your-fork-url>
cd Socail-Application
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/index.html
```

## Reporting Issues

Please open an issue with:

- a clear title
- steps to reproduce
- expected vs actual behavior
- screenshots if relevant

## Code Quality

- Keep JavaScript simple and understandable.
- Ensure HTML and CSS remain well-structured.
- Avoid introducing broken links or invalid paths.
- Test the app in the browser after making changes.

Thank you for helping improve the project.
